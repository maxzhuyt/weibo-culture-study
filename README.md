# weibo-culture-study

一份微博热搜数据集，覆盖 2019年10月到2026年9月，将近7年。每天上榜的热搜话题、话题
分类，以及一部分话题对应到的真实微博帖子（链接、评论数、正文摘要），都在里面。

用于研究中国社交媒体上公众议题结构随时间的变化。

*A multi-year (2019–2026) archive of Weibo hot-search topics, classified and linked to the
actual posts behind them. See file tree below; headers are kept bilingual where useful.*

---

## 先说清楚：这个仓库里有什么、没有什么

**有的**：
- 每天的热搜话题（标题、热度、排名）
- 每个话题属于哪一类（社会民生/国际时政/娱乐/…）
- 社会民生+国际时政这两类话题，找到了对应的真实微博帖子，包括帖子链接、评论数、
  发帖日期、正文前400字

**没有的**：
- **帖子下面的具体评论内容本身**。我们只定位到了帖子、知道它有多少条评论，但还没
  有抓评论文本，这是下一步的工作，不在本仓库范围内。
- 任何账号密码、登录凭证。抓取帖子时用了研究者自己的微博账号搜索，这个过程不需要、
  也没有保留任何凭证信息。

### lxw15337674_2025 是什么、为什么会有两份数据

`lxw15337674` 是另一个公开数据源的名字，来自 GitHub 用户 `lxw15337674` 维护的热搜
归档仓库，字段比我们主要用的数据源（weibotop.cn）更丰富——带微博官方自己的话题分类、
阅读数、讨论数。可惜这个源只往回存了一年多的数据，没法用来做跨年大规模采集。

所以实际做法是：先拿这份字段齐全的2025年数据，把整套方法（分类→筛选→找对应帖子）
验证一遍，确认流程可靠之后，才换成覆盖面更广的 weibotop.cn 去抓完整的7年。两份数据
都是独立完整、可以直接用的，`lxw15337674_2025/` 不是 `weibotop_2019_2026/` 的半成品
或者旧版本。

## 热搜话题是怎么分类的

每条热搜话题分到下面8类之一，只看标题判断，不依赖经常缺失的描述文字：

| 代码 | 类别 | 代码 | 类别 |
|---|---|---|---|
| S | 社会民生 | T | 体育 |
| N | 国际涉外 | C | 科技商业 |
| E | 娱乐 | P | 官方宣传 |
| L | 生活文化 | G | 游戏电竞 |

主数据里重点关注 S（社会民生）和 N（国际涉外）这两类，我们去找对应真实帖子的范围
就是这两类。

分类是大语言模型做的，准确性用 `validation/gold_standard/` 里的人工标注验证过：和
另一个独立模型标注的一致性，8类整体是 Cohen's κ = 0.75；聚焦到"是不是社会民生类"
这个筛选阶段真正依赖的判断上，一致率能到0.92，更高。

## 每条"找到的帖子"记录里有什么（posts.csv）

```
topic, date, weibo_cat, peak_hot, best_rank, status,
p1_comments, p1_url, p1_mid, p1_date, p1_text,   ...  p2_ ~ p5_ 同样的字段,
inperiod_comment_sum, global_top_comments, global_top_date
```

`p1`到`p5`是按评论数排序、且发帖日期落在热搜日期前后7天内的最多5条候选帖子，`p1`是
评论数最高的那条，"是否找到帖子"看的就是这一列。`p1_text`是帖子正文的前400字。

## 想自己重新跑一遍？

`scripts/` 里是完整的代码，三步走：

```bash
pip install -r requirements.txt

# 1. 抓每天的热搜榜（不需要登录，纯公开网页）
python scripts/fetch_weibotop.py OUT.csv --start 2019-10-26 --end 2026-09-19

# 2. 给每条话题分类（需要一个 OpenRouter API key）
KLAB_OPENROUTER_KEY=你的key python scripts/label_topics.py topics.jsonl labels.json

# 3. 给筛出来的话题找对应的真实帖子（需要你自己的微博登录Cookie）
python scripts/find_posts.py queue.jsonl posts.csv --cookie 你的cookie文件路径
```

第3步要用你自己的微博账号登录，从浏览器开发者工具里复制 Cookie。这个仓库不提供、
也不包含任何人的 Cookie。

## 已知的局限

- 热搜榜本身有一天固定缺一个小时的数据，因为每天的数据来自一个第三方抓取站点，不是
  我们自己24小时值守。
- 越早期的话题，找到对应真实帖子的成功率略低（2019年约89%，2026年约98%）。老话题的
  名字有时会被后来的热搜重复使用，搜索容易搜到不相关的近期帖子。
- 分类是模型做的，不是人工逐条核对，想知道可靠程度看上文的验证数据。

更详细的方法说明见 `docs/weibo_data_summary_2026-09-30.pdf`。
